# Fixed Event Return Matrix

เหตุการณ์เป็นปัจจัยภายนอกที่ผู้เล่นควบคุมไม่ได้ แต่ผู้เล่นควบคุมสัดส่วนพอร์ตได้ ทุกค่าด้านล่างเป็นผลตอบแทนตายตัวของสินทรัพย์เมื่อเหตุการณ์เกิดขึ้น และไม่มี `exposure`, ช่วงสุ่ม หรือโบนัสจากสไตล์มาคูณซ้ำ

| เหตุการณ์ | ตราสารหนี้ | กองทุนรวม | หุ้น | คริปโต |
|---|---:|---:|---:|---:|
| เงินเฟ้อ | -10% | +5% | +10% | +15% |
| สงคราม | +10% | -5% | -10% | -15% |
| โรคระบาด | +5% | 0% | -15% | +10% |
| ภัยธรรมชาติ | +10% | -5% | -20% | -5% |
| วิกฤตต้มยำกุ้ง | -20% | -5% | -10% | +15% |
| สงครามค่าเงิน | -15% | +5% | +15% | +15% |
| ฟองสบู่สินทรัพย์ | +15% | 0% | -15% | -20% |
| สงครามการค้า | +5% | -5% | -20% | 0% |
| ความไม่แน่นอนทางการเมือง | +10% | 0% | -10% | -20% |

สูตรผลรวมพอร์ต:

```text
ผลตอบแทนพอร์ต = Σ (สัดส่วนสินทรัพย์ × ผลตอบแทนของสินทรัพย์ในเหตุการณ์)
```

ตัวอย่างพอร์ต 25% เท่ากันเมื่อเจอเงินเฟ้อ:

```text
(25% × -10%) + (25% × 5%) + (25% × 10%) + (25% × 15%) = +5%
```

กติกาประกอบ:

- เงินสดรับผล 0% จาก Matrix แต่ถูกเงินเฟ้อลดกำลังซื้อเมื่อจบบท
- บท 1 ลดผลขาดทุนของทุกสินทรัพย์ได้สูงสุด 5 จุดเปอร์เซ็นต์ โดยไม่เปลี่ยนขาดทุนเป็นกำไร
- บท 2 ไม่มีตัวปรับตามวัย
- บท 3 หุ้นและคริปโตที่ติดลบเสียเพิ่ม 5 จุดเปอร์เซ็นต์ ส่วนตราสารหนี้ที่เป็นบวกได้เพิ่ม 5 จุดเปอร์เซ็นต์
- บท 4 หุ้นและคริปโตที่ติดลบเสียเพิ่ม 10 จุดเปอร์เซ็นต์ ส่วนตราสารหนี้ที่เป็นบวกได้เพิ่ม 5 จุดเปอร์เซ็นต์
- คลื่นตามใช้เฉพาะค่าติดลบของเหตุการณ์เดิมที่ความแรง 50% และไม่ให้กำไรซ้ำ
- มิจฉาชีพเป็นเหตุการณ์เสริมและไม่อยู่ใน Matrix
- แหล่งข้อมูลจริงของเกมอยู่ที่ `src/game/engine/data/events.js`
