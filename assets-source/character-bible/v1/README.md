# Character Bible v1 — Owner Review Gate

Status: All four canonical character sheets were approved by the Project Owner on 2026-08-21. The five target mockups are review candidates and are not approved runtime screens yet.

## Shared art direction

- Cozy contemporary pixel-fantasy adventure on a warm neutral presentation sheet.
- Mobile-first readability: identity must survive at 48–64 px through silhouette and equipment, not color alone.
- Equal visual status across all four investment styles.
- Required intent states represented on each sheet: idle, selected, thinking, brace, hit, celebrate, recover and summary, plus portrait/token/turnaround exploration.
- No combat action, prediction, immunity, guaranteed return, currency, shop, collectible or new game mechanic.

## Review checklist

1. Approve or request revisions for the canonical face, proportions, silhouette, costume and equipment of each character.
2. Confirm Trader reads as responsive rather than predictive.
3. Confirm VI reads as a fundamentals/value seeker rather than guaranteed growth.
4. Confirm Medium reads as adaptable rather than reckless or combat-led.
5. Confirm Long-term reads as patient rather than invulnerable.
6. Confirm all four remain equally appealing and distinguishable in grayscale.

Approved sheets are stored in `approved/`; original draft evidence remains in `drafts/`. Five real-content target mockups are stored in `mockups/` for the second owner-review gate. Thai text in AI mockups is layout evidence only: runtime implementation must use real DOM text from the application, not rasterized copy.

Do not batch-produce final states or wire these images into `src/assets` until the five mockups and frame family are approved.
